Feature Ideas for CS 1.6 Maps

Select any that interest you — you can pick multiple

A

Map Ratings & Comments

Users rate maps (thumbs up/down or stars) and leave short comments. Shows community quality signal on each map card.

B

Tags & Categories

Admin tags maps by type (de_, cs_, fy_, aim_, surf_, etc.). Users can filter by tag in addition to searching by name.

C

Map Screenshots

Upload preview images with each map. Shown as a thumbnail on the card, expandable on click. Admin can attach screenshots during upload or approval.

D

Batch Install

Checkboxes on map cards + an "Install Selected" button. Download and install multiple maps in one go with a combined progress view.

E

Map Packs / Collections

Admin curates named packs (e.g. "Classic Competitive", "Surf Pack"). Users install an entire pack with one click.

F

Download / Install Counter

Track how many times each map has been downloaded or installed. Show a popularity ranking or sort option.

G

Map Versions & Changelog

Allow re-uploading a new version of a map. Show version history and auto-prompt users who have the old version installed to update.

H

Submission Status Notifications

Email or in-app notification when a submitted map is approved or rejected, instead of having to check the submissions page manually.
